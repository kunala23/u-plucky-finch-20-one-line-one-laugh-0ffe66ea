A single funny line of at most 200 characters, written to `/output/entry.txt` by a small deterministic TypeScript program. The program scores three candidate lines against the judge's five published criteria and writes the winner: an AI that was asked for a one-line joke and apologised in three paragraphs.

## Run it

